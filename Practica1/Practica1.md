1. ¿ Cuáles son las principales diferencias entre Haskell y Rust?

Haskell es un lenguaje de paradigma funcional, tiene funciones predeterminadas de modo que se pueda utilizar menos codigo, Haskell evita los efectos secundarios (se obtiene siempre el mismo resultado de salida cuando se ingresa una y otra vez los mismos valores de entrada), se basa en una teoria matematica, haskell emplea un sistema de tipo datos estaticos y cuenta con un sistema de inferencia de datos, mientras que rust es un leguaje multiparadigma, tiene una interfaz simple, y fomenta la inmutabilidad que es que por defecto las variables no pueden ser modificadas una vez asignadas, tiene una compilacion nativa y estatica.
